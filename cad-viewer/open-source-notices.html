Project repository / 项目仓库

Golden Luck CADViewer on GitHub. The matching LibreDWG source, modification markers, build instructions and distributed-file checksums are recorded in CORRESPONDING_SOURCE.md.

Application code / 应用代码

The application is derived from mlightcad/cad-viewer and includes code under the MIT License. Because the distributed viewer directly integrates GPL-3.0-or-later LibreDWG components, the combined viewer distribution is offered under GPL-3.0-or-later. The original MIT terms remain available for independently used MIT-covered source files. Retained texts: MIT and GPL-3.0-or-later.

DWG parser / DWG 解析器

The bundled LibreDWG JavaScript and WebAssembly components are distributed under GPL-3.0-or-later. This release uses GNU LibreDWG 0.14.8556 and mlightcad/libredwg-web 0.7.9 with the modifications and build information published in the corresponding-source directory. See the GPL licence text, matching source snapshot, mlightcad/libredwg-web and GNU LibreDWG source.

3D import / 3D 导入

The STEP, IGES and BREP import path uses occt-import-js 0.0.23 under LGPL-2.1. It incorporates Open CASCADE Technology, which uses LGPL-2.1 with the Open CASCADE exception. Retained texts: occt-import-js licence, Open CASCADE licence and Open CASCADE exception.

Other bundled components / 其他组件

  • The SHX parser notice is available in shx-parser-LICENSE.txt.
  • The font engine bundle includes the SHX parser and supporting libraries such as iconv-lite, buffer, ieee754 and safe-buffer; their applicable notices must be retained when redistributing the bundle.
  • The public viewer self-hosts the Basic, Tenor Sans and VT323 drawing-font data sets. Their Open Font License texts are retained under the public font-data directory. Other user-supplied font files remain governed by their own licences.
